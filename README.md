# StudyHub-SDLC
SDLC Assignment 1

# Repository Tasks
1. Create one shared GitHub repository and give both partners push access. 
2. Create a README.md that names the project, explains its purpose, and lists the 4 requirement IDs from 
Part 1. 
3. Each partner creates at least one feature branch and makes meaningful changes connected to one or 
more requirement cards. 
4. Each partner makes meaningful, incremental commits. Commit messages must explain what changed. 
Avoid messages such as “update” or “fix.” 
5. Merge both feature branches into main. 
6. Deliberately create and resolve at least one merge conflict. Document what caused the conflict and how 
your team resolved it. 
7. Add two simple environment configuration examples, such as .env.development.example and 
.env.production.example. Use placeholder values only. Do not commit real passwords, API keys, or 
secrets. 
8. In README.md, explain your branching and merging workflow, the merge conflict, and how your selected 
Blue Green or Canary strategy would apply to the repository.
